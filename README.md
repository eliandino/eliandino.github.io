Dystopic GitHub Portfolio
A responsive, dependency-free portfolio for Eli Andino. GitHub Pages publishes the production site directly from the docs folder.
Personalize before launch
In docs/index.html, replace your.email@example.com with your email address.
Update project descriptions and GitHub links as your work evolves.
Commit and push this folder to a GitHub repository.
Publish with GitHub Pages
Open the repository on GitHub.
Go to Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select your branch (normally main) and the /docs folder.
Click Save.
GitHub will display the public URL after the first deployment completes.
Local preview
Open docs/index.html in a browser, or serve the repository with any static file server.
